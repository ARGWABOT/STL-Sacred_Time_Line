# Contributing

STL Studio is changed only by its author: this project does not accept code changes from others (pull requests), and its official versions are published only by its author.

**Bug reports are welcome.** If something fails, open an issue on GitHub with the bug report form: it asks for your system (Windows, Mac or Linux), the Studio version, what you did and what happened and, if a review failed, what «What happened with the review» says.

You can change your own copy as much as you like (the director can help you customize it): that copy is yours, under the [PolyForm Shield 1.0.0](LICENSE) license. You may use it for any project, commercial ones too; what you may not do is offer a product that competes with STL Studio, such as selling it or republishing it under another name. Whoever passes on a copy passes on the license and its «Required Notice» line.
